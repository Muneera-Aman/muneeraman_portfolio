# Menoa-inspired Portfolio

This is an original HTML/CSS/JavaScript recreation inspired by the public visual structure of the Menoa Framer portfolio template.

Files:
- index.html — page structure/content
- style.css — responsive styling
- script.js — smooth scrolling and reveal animations

Open index.html in a browser, or deploy the folder to GitHub Pages, Vercel, Netlify, etc.

Replace the demo text, email, project cards, and social links with your own portfolio information.
